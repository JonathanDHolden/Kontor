# Changelog

All notable changes to `kontor/documents` are documented here.

## [1.1.0] - 2026-10-09

### Added

- Bounded, cycle-safe shared template sections using `{{> template.key}}`.
- Ordered field discovery for dynamic letter and contract preview forms.
- Optional company-bound PDF storage, safe dated filenames and company file listings.

### Changed

- The template editor opener is now labelled “Edit template”; publishing still creates an immutable new version.

## [1.0.0] - 2026-09-27

### Added

- First public release. Kontor Documents: templates, HTML/PDF rendering, multilingual output, immutable issued-document snapshots.
